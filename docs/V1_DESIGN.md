# 枝理 1.0 设计与验收

## 主工作流

打开即进入画布，由中心主题起笔。左侧工具栏放保存、新增、撤销和查找，右侧集中两种布局及适应窗口。米白画布、墨绿根节点、浅绿一级分支和琥珀色选中描边提供层级提示。经典图按根节点的子级顺序交替分配左右两侧，结构图按同一顺序从左至右展开。两种布局都以节点文本的实际尺寸和子树占用空间计算位置。

编辑器覆盖在节点原位，保留系统文本编辑控件的换行和输入法行为。画布快捷键在编辑时暂停。拖放改变层级或兄弟节点顺序，阻止把分支放进自己的后代。编辑、折叠、删除、拖动和布局切换进入同一条撤销历史。画布保留已有节点和连接线图元，选中节点时只改描边。

窗口启动时按工作区尺寸调整；窄窗口切换紧凑工具栏。画布缩放比例与系统 DPI 分离。适应窗口后，调整窗口大小会重新计算画布比例；手动缩放后保留用户比例。Qt 离屏测试覆盖 100%、125%、150%、200% 缩放和 360×280 逻辑像素紧凑窗口。

默认中文字体为内置思源黑体，可在外观设置选思源宋体或已安装字体。界面字号范围 9–22 pt，导图字号范围 9–32 pt，中心主题在设定字号基础上增加 4 pt。界面与节点各自可切换常规和粗体。浅色与高对比配色为本地偏好，不改变原生导图数据。

## 文件与恢复

本轮将 `.smap` 定义为 UTF-8 JSON v1，沿用原型的 `simplemap-json` 格式标识。此处采用单文件 JSON，交接草案中的 ZIP 资源容器可在出现附件需求时另行设计。读取原型生成的 `.smap.json`，保留节点 ID、文字、子节点顺序、折叠和当前布局。坐标由布局计算。读取验证根节点、重复引用、环、孤立节点及大小上限。文件上限 50 MiB，节点上限 100,000，深度上限 512，单主题文字上限 100,000 个 UTF-16 码元。

手动保存和导出使用 QSaveFile 原子替换。恢复快照独立保存到当前用户的应用数据目录，包含正在编辑且已由输入法提交的文字。自动恢复实例锁避免两个进程相互覆盖同一快照。恢复后首次保存走另存为流程。PDF 使用单页 A4 并自动选择方向。对大图优先使用矢量导出保留缩放空间。

## 已验证

- 在 Apple Silicon Mac 上，以 Rosetta 运行 x86_64 Qt 5.15.2 Release 构建。交接原型和更新后的版本均已成功编译。
- Qt 自动化覆盖双击原位编辑、中文输入事件、键盘新建、拖放、折叠、布局切换、子树删除与撤销、中文路径读写、旧扩展名、无效结构拒绝、恢复快照和三种导出。
- 本机离屏生成两张界面预览，并用 100、500、1000、3000 节点的合成导图测试打开和布局切换。构建和测试的原始记录位于体验包内。

## 正式发布前验收

- 在 D2000 + 银河麒麟 V10 和 Windows x64 上分别打包、离线安装、启动和卸载，确认 Qt 依赖、中文输入法候选、字体、路径和 DPI。
- 用两平台生成的同一批文件进行双向往返，检查三种导出的中文渲染。
- 在 D2000 上实测 3000 节点、平移缩放帧延迟、连续两小时编辑和真实异常退出恢复，记录设备与图形环境。Mac 上的离屏数据只用于本轮开发对照。
