# 产品规格草案 — 枝理（暂定品牌）/ SimpleMap

## 产品定位
完全离线、纯本地文件、无 AI、无账户、无云同步、无模板商城的专业桌面导图工具。强调简单、稳定、流畅、快捷键优先。

## 目标平台
主平台：银河麒麟桌面 V10、飞腾 D2000 CPU（ARM64）、16 GB 内存；副平台：Windows x64。银河麒麟具体补丁版本、系统 Qt 库、图形环境、中文输入法尚待实测。

## 视图与模型
- 同一份树形数据支持「经典思维导图（左右发散）」和「专业结构图（自上而下）」两种布局。
- 切换布局不能改变节点 ID、层级、顺序、文本、备注和资源关联。
- 布局呈现与持久化数据模型分离。位置可作为缓存，不可成为唯一层级依据。

## V1.0 必备功能（目标，非现状）
1. 新建、打开、保存、另存为、安全写入、自动恢复。
2. 子节点/同级节点增删改、折叠展开、节点拖拽重排、选中状态清晰。
3. 双击原位编辑与中文输入法完整支持。
4. 两类布局互换、自动布局、画布拖动缩放、适合不同 DPI 的尺寸。
5. 撤销重做、查找节点、键盘优先操作。
6. PNG/SVG/PDF 导出；跨平台原生文件往返无损。
7. 大图基本性能优化；崩溃恢复和误操作防护。
8. ARM64 麒麟与 Windows 可安装/可运行版本及说明。

## 推荐快捷键
- Enter：新增同级；Tab：新增子级；F2：原位编辑；Delete：删除；Space：展开/折叠（仅非编辑状态）。
- Ctrl+1：经典布局；Ctrl+2：结构图布局；Ctrl+S：保存；Ctrl+O：打开；Ctrl+Z/Ctrl+Y：撤销/重做；Ctrl+F：搜索。
- 编辑状态下不得抢占中文输入、空格、回车及 IME 候选确认。

## 明确排除
AI 生成、在线账户、云服务、复杂协作、营销与订阅入口、复杂模板商城、甘特/资源管理。

## 兼容性策略
优先实现版本化自有格式，提供稳定的数据模型。MindMaster/MindManager/XMind 专有格式转换需基于真实样本验证，不能在未验证前承诺无损兼容；优先采用产品自身官方导出中间格式。禁止复制第三方受保护代码/图标。
