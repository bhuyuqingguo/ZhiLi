## 枝理 ZhiLi 1.0.4

- **关系线**：Ctrl+R 选起点后点击终点，Ctrl+Shift+R 创建直线。双击或 F2 编辑说明，拖动黄色控制点调整曲率，Delete 删除，支持复制、剪切、粘贴和撤销。
- **外框**：选中一个或多个分支后按 Ctrl+Shift+B，自动包住分支及后代。内容、折叠和布局改变时随之调整；双击编辑标题，删除外框保留主题。
- **浮动主题**：Alt+F 后点击落点，或双击空白处。主题可添加子级、整组移动、Alt+方向键微移；将分支拖到空白处可独立摆放，再拖到目标主题接回树结构。Ctrl 拖动复制，Esc 取消拖拽。
- **编辑习惯与快捷键设置**：补齐父主题、批量录入、大纲侧栏、拆分与合并、层级展开和字形设置。快捷键可搜索、改绑、检查冲突和恢复默认，另附 MindMaster 官方目录对照及尚未实现的差异。
- **启动体验**：默认最大化，枝条生长动画约 1.65 秒，点击或按 Esc 跳过，帮助菜单可关闭。

新元素使用不加密的 SMAP v2 JSON 保存；没有新元素的导图仍写 v1。旧版枝理会拒绝 v2，请使用 1.0.4 或更新版本继续编辑。复制分支只保留内部关系线，外框裁剪到被复制的主题；单独复制关系线或外框要求引用的主题仍在目标文件中。

SMAP、PNG、SVG、PDF 保留新元素；draw.io 导出为可编辑图形。PPTX、Visio、OPML、FreeMind、Canvas 和文本导出尚未完整映射新元素，含这些元素时会拒绝有损写出并提示可用格式。普通树状导图的原有导出不受影响。外框精细样式、智能关系线避障、概要和标注仍未实现。

## 完整包

- `ZhiLi-v1.0.4-Windows-x64.zip`：解压后运行 `ZhiLi/simplemap.exe`。
- `ZhiLi-v1.0.4-Linux-ARM64-Portable.tar.gz`：解压后运行 `ZhiLi/ZhiLi`。需要 glibc 2.31 或兼容版本及系统 Qt5 运行库。

## 从 v1.0.3 增量升级

- Windows：`ZhiLi-v1.0.3-to-v1.0.4-Windows-x64.update.zip`。
- Linux ARM64：`ZhiLi-v1.0.3-to-v1.0.4-Linux-ARM64-Portable.update.zip`。

同时下载 `ZhiLi-v1.0.4-update.py` 和对应 SHA-256 文件。更新器验证原版基线，在新目录重建新版，保留旧目录。发布流水线实际应用增量包并逐文件验证结果。

Windows 程序未签名。银河麒麟 V10 SP1／飞腾 D2000、中文输入法和混合 DPI 仍需真机验收。
