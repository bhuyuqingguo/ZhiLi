## 枝理 ZhiLi 1.0.5

这版重点补齐从录入、整理到回溯的日常编辑流程，并修复双击编辑时的白底矩形，文字直接在主题原位透明编辑。

- **选择性粘贴（Ctrl+Alt+V）**：原始分支、缩进大纲、Markdown、合为一个主题或仅粘贴已复制样式；可选子级或同级，决定是否保留文字样式和备注。原生分支复制保留图片与链接。
- **连续格式刷（Ctrl+Shift+C）**：选中来源，连续点击目标主题，Esc 退出；Ctrl+Shift+V 可批量粘贴已复制的文字样式。工具栏与右键菜单可直接进入。
- **查找替换（Ctrl+F）**：实时结果列表、逐项定位、替换一次及全部替换；支持全图或当前分支、主题文字与备注、大小写和折叠主题。一批替换一次撤销。按字面匹配，不解释正则表达式。
- **主题图片（Ctrl+Shift+P）**：插入、替换和移除图片，也可直接粘贴剪贴板图片。图片自动缩放并嵌入文件，复制、撤销、保存重开均保留。每个主题一张，导入时最长边压缩至 1600 像素。
- **主题链接（Ctrl+K）**：每个主题最多 32 个网址、邮箱或本地文件链接；双击「链接」标记选择打开。文件链接仍指向原文件，未作为附件嵌入。
- **本地历史版本**：保存时保留快照，已保存文件在编辑中每分钟再留一份；内容未变化不重复。每个文件最多 30 份、200 MiB，可预览并恢复，恢复不立即覆盖磁盘且可以撤销。
- **直接粘贴 Markdown**：Ctrl+V 识别标题和列表，转换为层级；选择性粘贴可强制 Markdown 或纯文字。使用大纲解析，代码块与 Markdown 富文本样式不作为主题内容保留。

图片与链接保存在不加密的 **SMAP v3 JSON** 中，1.0.5 读取 v1/v2/v3。没有图片和链接的文件仍按已有内容写 v1 或 v2；旧版本不能打开 v3。PNG/SVG/PDF 保留图片和链接标记的外观，链接标记不是可点击的导出超链接。PPTX、draw.io、Visio、OPML 等交换目标暂不能完整保留新内容，会明确拒绝有损导出。其他软件原生文件内图片、附件与链接的自动迁移尚未补齐。

仍有差异：格式刷目前复制主题级文字样式，不包含外框或容器样式；暂不支持局部富文本、主题间链接、云历史及自动下载网页图片。快捷键对齐本次编辑命令，并不代表全量功能与 MindMaster 一致。

## 完整包

- `ZhiLi-v1.0.5-Windows-x64.zip`：解压后运行 `ZhiLi/simplemap.exe`。
- `ZhiLi-v1.0.5-Linux-ARM64-Portable.tar.gz`：解压后运行 `ZhiLi/ZhiLi`。需要 glibc 2.31 或兼容版本及系统 Qt5 运行库。

## 从 v1.0.4 增量升级

- `ZhiLi-v1.0.4-to-v1.0.5-Windows-x64.update.zip`
- `ZhiLi-v1.0.4-to-v1.0.5-Linux-ARM64-Portable.update.zip`

同时下载 `ZhiLi-v1.0.5-update.py` 和对应 SHA-256 文件。更新器验证原版基线，在新目录重建新版，保留旧目录。发布流水线实际应用增量包并逐文件验证结果。

测试覆盖选择性粘贴与错误回滚、Markdown 层级、范围替换、图片和链接复制/重开、格式刷、历史去重与保留上限、恢复与撤销，以及多 DPI 的界面回归。Windows 程序未签名。银河麒麟 V10 SP1／飞腾 D2000、中文输入法和混合 DPI 仍需真机验收。
