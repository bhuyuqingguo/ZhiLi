## 枝理 ZhiLi 1.0.6

这版改的是打开方式。解压之后外层只有一个文件夹和一个入口，双击那一个就能用，不需要安装，也不需要管理员。

- Windows 10／11 x64：解压 `ZhiLi-v1.0.6-Windows-x64.zip` 后双击 `ZhiLi.exe`。程序和 Qt 运行库在旁边的 `ZhiLi/` 里。`ZhiLi.exe` 自带图标。第一次运行在桌面写下 `枝理.lnk`。
- 银河麒麟 V10 ARM64：解压 `ZhiLi-v1.0.6-Linux-ARM64-Portable.tar.gz` 后双击 `zhili.sh`。脚本权限是 0755。程序在旁边的 `zhili/` 里。这份二进制在 Ubuntu 20.04 arm64 的 Qt 5.12.8 上编译，导入的 glibc 最高是 2.29，还需要系统里的 Qt5 Svg、Widgets、Gui、Core。桌面快捷方式的图标是包内 `zhili.png` 的绝对路径，并写有 `StartupWMClass=ZhiLi`。

入口换了位置之后，再次打开会把快捷方式改到新位置。用户删掉快捷方式之后，不会自动再造。

这次发布只有这两个压缩包和 `SHA256SUMS.txt`。不附带 macOS 包，不另打 Windows 7 包，也不附带增量包。v1.0.5 的更新器只对比旧布局里的 `ZhiLi/` 目录，对不上新的入口文件。

Windows 包用 Qt 5.15.2 MinGW 官方库交叉编译，程序未签名。exe 的子系统版本是 6.1，链接的是 `msvcrt.dll`，不是 UCRT。入口、主程序、Qt 四个库、插件和随包的 MinGW 运行库，导入表里没有 `GetSystemTimePreciseAsFileTime`、`CreateFile2`、`GetDpiForMonitor` 这些 Windows 8 及以后的函数。Qt 5.15 的支持平台包含 Windows 7。没有在 Windows 7 上实际开机。这次不另打 Windows 7 包。Qt Base 与 Qt SVG 5.15.2 源码仍是 v1.0.5 发布页上的那两份。

编辑功能与 1.0.5 相同。银河麒麟 V10 SP1／飞腾 D2000、中文输入法和混合 DPI 仍需真机验收。
