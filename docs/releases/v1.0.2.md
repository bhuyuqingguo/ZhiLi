## 枝理 ZhiLi 1.0.2

这版把格式转换放到主工具栏，并打磨了多分支整理、中文排版和从旧导图迁移的流程。

- **整组拖动**。多选后可一起移动或按住 Ctrl 复制，吸附到目标后重新排布，支持整次撤销。
- **分支聚焦与快速交付**。可进入当前分支单独编辑，按 Esc 返回全图，也可复制透明图片或导出当前分支为可编辑 PowerPoint、SVG、PDF 或独立 SMAP。
- **本地格式转换**。主工具栏和窄窗口都可直接进入转换。新增已验证版本的 MindMaster / EdrawMind 二进制 EMMX，以及 MindNode Classic / Next、MindMeister、Mindomo 原生主题树。支持 Visio、draw.io 和 PowerPoint 与开放 SMAP 之间的结构转换。 [文件兼容范围](https://github.com/bhuyuqingguo/ZhiLi/blob/v1.0.2/docs/FORMAT_COMPATIBILITY.md)
- **中文字体和批量样式**。新增霞鹜文楷 GB 轻便版和得意黑，系统中文字体优先显示。主题可批量应用或粘贴对齐方式、字体、字号、字重和颜色。
- **应用图标与文档**。Windows EXE、macOS 应用包和 Linux 桌面入口接入枝理图标。README 增加四种布局、分支聚焦、批量样式、中文字体和格式转换实拍。 [查看新版 README](https://github.com/bhuyuqingguo/ZhiLi/tree/v1.0.2#readme)

## 下载与验收

- **Windows x64**。解压 `ZhiLi-v1.0.2-Windows-x64.zip` 后运行 `ZhiLi/simplemap.exe`。程序未做代码签名。
- **Linux ARM64**。解压 `ZhiLi-v1.0.2-Linux-ARM64-Portable.tar.gz` 后运行 `ZhiLi/ZhiLi`。需要 glibc 2.31 或兼容版本及系统 Qt5 运行库。

下载包附 SHA-256 校验文件，Windows 包使用的 Qt 对应源码也随本版发布。银河麒麟 V10 SP1／飞腾 D2000 真机、混合 DPI、中文输入法和 PowerPoint／WPS 兼容性仍需现场验收。
