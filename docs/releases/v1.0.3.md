## 枝理 ZhiLi 1.0.3

- **分屏聚焦**。左侧显示全图概览，右侧编辑当前分支。点击概览中的其他主题即可切换，编辑和撤销会同步到全图。窄窗口自动改为上下排列，按 Esc 恢复原全图视图。
- **框选与快捷键提示**。右下角可切换框选模式。状态栏根据编辑、拖动、多选和聚焦状态给出快捷键提示。新增格式转换、导入、分支导出、样式复制与粘贴等快捷键。
- **离线帮助与关于**。按 F1 查看中文操作指南和快捷键速查。「帮助 → 关于枝理」显示应用版本及运行环境。
- **剪贴板可靠性**。Windows 剪贴板忙时会重试。分支剪切先确认写入成功，再移除原分支。复制失败时会在状态栏提示。

## 完整包

- Windows x64 下载 `ZhiLi-v1.0.3-Windows-x64.zip`，解压后运行 `ZhiLi/simplemap.exe`。程序未做代码签名。
- Linux ARM64 下载 `ZhiLi-v1.0.3-Linux-ARM64-Portable.tar.gz`，解压后运行 `ZhiLi/ZhiLi`。需要 glibc 2.31 或兼容版本及系统 Qt5 运行库。

## 从 v1.0.2 升级

- Windows x64 使用 `ZhiLi-v1.0.2-to-v1.0.3-Windows-x64.update.zip`。
- Linux ARM64 使用 `ZhiLi-v1.0.2-to-v1.0.3-Linux-ARM64-Portable.update.zip`。

同时下载 `ZhiLi-v1.0.3-update.py` 和相应的 SHA-256 校验文件。工具会核对原版便携包并把新版写到新目录。完整包和增量包均附校验文件。银河麒麟 V10 SP1／飞腾 D2000、混合 DPI 与中文输入法仍需现场验收。 [离线升级步骤](https://github.com/bhuyuqingguo/ZhiLi/blob/v1.0.3/docs/INCREMENTAL_UPDATE.md) · [界面实拍和操作说明](https://github.com/bhuyuqingguo/ZhiLi/tree/v1.0.3#readme)
