## 枝理 1.0.1

枝理是离线桌面思维导图编辑器，导图保存在本机。

- 四种布局包括经典双侧、向右展开、向左展开和纵向结构图。
- 连线支持自动搭配、直角、直线和曲线。拖动靠近节点时可吸附，插入同级主题时显示对齐参考线，落点确定后重新排布和布线。
- 支持多选、分支复制剪切粘贴和主题样式批量编辑。主题文字默认居中，布局、线型与主题样式随 `.smap` 保存。
- 提供 80 个模板和 128 个透明矢量符号，图标可切换简约 2D 和立体拟物风格。
- 支持导入 MindManager `.mmap` 和旧版 XML `.emmx` 的主题结构，导出 PNG、SVG、PDF 和可编辑 PowerPoint。

## 下载与验收

- **Windows x64** 下载 `ZhiLi-Windows-x64.zip`，解压后运行 `ZhiLi/simplemap.exe`。应用未做代码签名。
- **Linux ARM64** 下载 `ZhiLi-Linux-ARM64-Portable.tar.gz`，解压后运行 `ZhiLi/ZhiLi`。运行需要 glibc 2.31 或兼容版本，以及系统 Qt5 运行库。

两个平台的构建和自动化测试均通过后才发布下载包。银河麒麟 V10 SP1／飞腾 D2000 真机、实际中文输入法、混合 DPI 及 PowerPoint／WPS 兼容性仍需现场验收。压缩包附 SHA-256 校验文件，Windows 包使用的 Qt 对应源码也附在本页。
