## 已实现

## 验证与限制
Linux Release 14/14、ASan/UBSan 14/14 通过（未启用泄漏检查）；ARM64 QEMU/Qt5.12.8 模拟测试 14/14 通过。Windows 仅交叉构建与依赖检查，尚未真机验证；ARM64 包依赖兼容系统 Qt/glibc，未在真实麒麟/飞腾上验收。PPTX 已通过结构检查和 LibreOffice 渲染，微软 PowerPoint 尚未实机验证。当前新版二进制 EMMX、Visio 互通和完全无损双向转换均不支持。
