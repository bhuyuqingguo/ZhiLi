# 枝理 SMAP v1 / v2 / v3 文件格式

`.smap` 是 UTF-8 编码的标准 JSON。文件直接存储主题树、样式和布局参数，默认没有加密、压缩、账号绑定或网络依赖。其他程序可以使用通用 JSON 库读写。旧文件名 `.smap.json` 仍可打开。

## 最小示例

```json
{
  "format": "simplemap-json",
  "version": 1,
  "root": "main",
  "nodes": [
    { "id": "main", "text": "项目计划", "children": ["work"] },
    { "id": "work", "text": "设计与验证", "children": [] }
  ]
}
```

## 顶层字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `format` | 字符串，必填 | 固定为 `simplemap-json` |
| `version` | 整数，必填 | 普通树为 `1`，含关系线、外框或浮动主题时为 `2`；含主题图片或链接时为 `3`；枝理 1.0.5 起读取三种版本 |
| `root` | 字符串，必填 | 中心主题的 ID |
| `nodes` | 数组，必填 | 所有主题，数组顺序没有语义 |
| `layout` | 字符串 | `mindmap` 为默认，`organization` 为纵向结构图 |
| `branchDirection` | 字符串 | 思维导图布局下可用 `left` 或 `right`，省略时双侧展开 |
| `connectorStyle` | 字符串 | `automatic` 为默认，也可用 `orthogonal`、`straight`、`curved` |

## 主题字段

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `id` | 字符串，必填 | 非空，在同一文件中唯一 |
| `text` | 字符串，必填 | 主题纯文字，可为空或含换行 |
| `imagePng` | 字符串 | v3：PNG 字节的标准 Base64；最多 12 MiB 编码文字，图像尺寸不超过 4096×4096；界面插入时最长边压缩至 1600 像素 |
| `links` | 字符串数组 | v3：最多 32 个 URL，每项最多 4096 字符，允许 http、https、mailto、file；外部文件不嵌入 |
| `notes` | 字符串 | 可选的纯文字备注，可含换行，最长 10 万个 UTF-16 代码单元 |
| `children` | 字符串数组，必填 | 按显示顺序排列的子主题 ID，无子级时为 `[]` |
| `collapsed` | 布尔值 | 默认 `false`，折叠时仍须存储全部后代 |
| `symbolId` | 字符串 | 可选的枝理内置符号 ID，未知 ID 可以保留 |
| `rootLane` | 字符串 | 双侧布局的中心直属分支可指定 `left` 或 `right`，省略时自动分配 |
| `style` | 对象 | 可选的文字样式 |

`style` 中可写 `alignment`（`center`、`left`、`right`，默认居中）、`family`（字体名）、`points`（9–48 的整数）、`bold`（布尔值）、`italic`、`underline`、`strikeOut`（三者均为布尔值，省略时为 `false`）和 `color`（`#RRGGBB`）。未指定的字体、字号、字重和颜色采用应用主题。字体和符号图像不嵌入文件。

## 读写规则

### v2 扩展字段

```json
{
  "floating": { "idea": [480, 260] },
  "relationships": [
    { "id": "link1", "from": "work", "to": "idea", "text": "补充", "straight": false, "bend": [110, 0] }
  ],
  "boundaries": [
    { "id": "frame1", "members": ["work"], "text": "交付范围" }
  ]
}
```

这是扩展字段片段，须与 `format`、`version`、`root`、`nodes` 合并。`floating` 的键须是存储树根的直属子主题 ID；该父子引用仅用于存储和遍历，不画树连线，也不参与主图自动布局。坐标是浮动分支根中心的场景坐标，分支内部仍自动布局，折叠中心不隐藏浮动分支。

关系线的 `from`、`to` 必须存在且不同，`bend` 为相对两端主题中心中点的二次曲线控制点偏移。外框 `members` 必须非空、引用现有主题且不重复；绘制范围包含这些主题的可见后代。两类对象的 ID 在对象集合中唯一，最长 128 个 UTF-16 代码单元；文字最长 10 万个；各类最多 10 万个；坐标及控制点必须有限且绝对值不超过 1000 万。

删除主题时清理失效关系线及外框成员，空外框删除；复制分支时重新生成对象 ID 和主题引用，只保留内部关系线及被复制的外框成员。PNG、SVG、PDF 保留视觉效果，draw.io 写成对应可编辑图形，但外部文件修改后重新导入仍按导入器的图结构映射，不保证原生语义往返。PPTX、Visio 和大纲等格式尚不能完整映射新元素时拒绝有损写出。

### 通用约束

- 所有节点须从 `root` 可达。除中心外每个节点只有一个父节点，不能有循环、断开的主题或重复引用。
- 枝理当前限制为文件 50 MiB、10 万个主题、最多 512 层边（中心深度为 0），每个主题文字最多 10 万个 UTF-16 代码单元。字体名和符号 ID 最长 128 个 UTF-16 代码单元。
- 写入器应保留 `children` 的顺序。外部工具可以自选 ID，只要文件内引用一致。除浮动分支的锚点外，画布坐标由读取方按布局计算。
- 枝理 v1 忽略未知字段，重新保存时可能丢弃这些字段。需要保留的自定义数据应留在源文件，或由转换器另行管理。未知文件版本应报错。
- 保存主题备注、斜体、下划线和删除线时请使用支持对应字段的枝理版本。早期版本重新保存可能丢失这些新增字段。
- 导入的文件保留在原位置，转换写入新的 `.smap`。树以外的关系、资源与样式属于各导入器的映射范围，参见[格式兼容清单](FORMAT_COMPATIBILITY.md)。
