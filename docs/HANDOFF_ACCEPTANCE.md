# V1.0 验收方案（目标而非实测）

## 功能
- 两种布局切换不更改节点 ID、文本、层级、顺序和附件引用。
- Enter/Tab/F2/Delete/Space 与输入法无冲突；鼠标双击编辑，支持撤销。
- 保存/打开/另存为、中文目录/长路径、意外退出后的自动恢复。
- 在 Windows ↔ 麒麟 ARM64 间完整文件往返；可导出 PNG/SVG/PDF。

## 性能目标（应在 D2000 真机测量）
- 常规节点编辑至可见响应，目标 <= 50 ms。
- 典型大小导图布局切换，目标 <= 300 ms（须说明节点数）。
- 1000 节点导图打开，目标 <= 2 秒。
- 拖动画布和缩放优先争取 60 FPS；必须记录 95 分位帧耗时、显示系统及图形驱动。
- 3000 节点能打开、搜索、保存，不出现不可恢复的卡死。
- 连续 2 小时编辑不崩溃；故障模拟后恢复最近持久化编辑状态。
这些均为建议目标，不是已达到的结果；如果指标不合理，依据设备真实数据讨论调整。

## 平台矩阵
麒麟桌面 V10 + 飞腾 D2000 ARM64 + 16GB，记录 `uname -m`、`/etc/os-release`、Qt 版本、桌面会话、输入法及字体；Windows x64 同样建立测试记录。

## 发布阻断项
不能编译/启动、保存丢失数据、崩溃恢复失效、中文输入不可用、布局切换破坏结构、目标 ARM64 不可安装/运行。
