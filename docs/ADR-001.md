# ADR-001 技术决策记录（初稿）
状态：暂定，待飞腾 D2000 + 麒麟桌面 V10 真机验证。

## 决策
使用 Qt5 Widgets + C++11 + QGraphicsScene / QGraphicsView；核心数据采用与视图分离的树形 JSON 结构。

## 理由
银河麒麟桌面 V10 的子版本 Qt 依赖可能存在差异；Qt5 与较旧桌面环境兼容性值得优先试验。不依赖 WebKitGTK 运行时。设计支持 Windows x64 与 Linux ARM64 原生构建。

## 风险
目标系统 Qt5 库版本不确定；字体回退、图形驱动、DPi、输入法以及软件仓库限制需要实测。Qt5 授权、部署静态/动态链接政策需要审查。

## 首个验证闸门
在目标机器记录 `uname -m`, `/etc/os-release`, `qmake -v`, `fc-match sans:lang=zh`，然后构建运行原型并测试中文输入、保存/打开、导出图像、布局切换。

## 不做的事情
AI、云服务、协同、账号、会员、复杂模板商城；不反编译或复制商业程序源码。
