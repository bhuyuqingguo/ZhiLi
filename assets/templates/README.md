# 枝理离线模板库

本目录提供 80 个原创参考模板。每个模板都包含可编辑的主题树，不需要网络、账号或额外下载。

## 使用方式

- 在应用中选择「文件 → 从模板新建」，按分类或关键词查找，预览后创建。
- 「适应预览」查看整体结构；「原大查看」按可读字号查看，拖动预览可平移。宽结构图也可以切换到「节点大纲」逐项阅读。
- 也可以直接打开 `assets/templates/files/` 下任意 `.smap` 文件。建议使用「另存为」保存自己的内容，保留原始模板。
- 模板创建的是独立副本，不修改模板库。所有节点均可修改、增加、删除、折叠；两种布局都可切换。

## 范围与使用提示

模板用于活动组织、体系梳理、能力分析和通用架构表达。内容是结构化起点，不是行业标准认证、已完成的评估结果或实际系统配置。

平台、无人系统和通信相关条目仅含科研资料分类、抽象接口和非操作性协作内容，不含作战、控制、实际网络地址或凭据。请按自己的需求替换节点、责任人和验证条件，并审查敏感信息。

全部模板内容为本项目原创，可与项目代码一同使用、修改和分发；未复制第三方模板或标准正文。

## 维护约定

- `catalog.json` 保存稳定 ID、分类、标题、说明、标签、推荐布局和节点数。
- `files/<id>.smap` 使用原生 `simplemap-json` v1 格式；标题、节点数和布局必须与目录一致。
- `../templates.qrc` 显式收录目录和全部文件。新增模板时同时更新三处并运行模板数据与界面测试。
- 模板节点使用短 ID 便于审阅；加载器会为每次创建重新分配 UUID。
