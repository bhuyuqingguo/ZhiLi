枝理使用帮助

枝理是离线桌面思维导图工具。新建导图或从「文件 → 从模板新建」开始，用 Ctrl+S 保存开放的 SMAP 文件。

录入和编辑

双击主题或按 F2 编辑；Space 从末尾编辑，Shift+Space 从开头编辑。编辑时 Enter 确认，Esc 取消，Shift+Enter、Ctrl+Enter 或 Alt+Enter 换行。Ctrl+Left / Right 或 Ctrl+Home / End 跳到文字开头或结尾。中文输入法组词期间 Enter 不会提前保存。

选中主题时 Enter 新建同级，Shift+Enter 在前面插入，Tab、Insert 或 Ctrl+Enter 新建子主题，Shift+Insert 插入父主题。Ctrl+M 打开批量录入窗口，每行一个主题，Tab 缩进。编辑文字时，Shift+Alt+Enter 从光标处拆成两个同级主题。

Delete 或 Backspace 删除整个分支，Shift+Delete 只移除所选主题并保留子级。Ctrl+Z 撤销，Ctrl+Y 或 Ctrl+Shift+Z 重做。

框选与整理

点击画布右下角的框选按钮，再从空白处按住左键拖动。也可以直接按 Shift 从空白处拖动。框与主题相交即可选中，Ctrl+单击可以逐项增减。开启框选时，可用中键拖动平移。

从任一选中主题拖动即可移动整组。拖到另一个主题中央可移入子级，靠近边缘可调整同级顺序。按 Ctrl 拖动会复制分支。Ctrl+Shift+F 打开批量主题样式。

选中一个分支后按 Ctrl+D，可在原分支后创建副本。右键菜单的「调整分支顺序」可以按标题排列当前主题的子主题。

Ctrl+Alt+Up / Down 向前或向后复制，Ctrl+Insert 复制为子主题。Ctrl+Shift+Up / Down 调整顺序，Ctrl+Shift+Home / End 移到同级首尾，多选时整组移动。Ctrl+[ 降为前项的子主题，Ctrl+] 提升一级。右键「调整分支顺序」还可合并所选同级主题，保留文字、备注和后代。

拖拽和框选中按 Esc 可取消。拖动分支到画布边缘会自动滚动画布。Home / End 选择同级首尾，Shift+Home / End 扩选，Ctrl+Home 定位中心。Ctrl+Shift+A 选择所有同级主题，Ctrl+Alt+A 选择下一级；右键「选择主题」还有父主题、整个分支和相同层级选择。

按 Ctrl+T 编辑主题备注，已有备注的主题可双击「备注」标记打开。备注随枝理导图保存。

浏览导图

工具栏可切换经典双侧、向左展开、向右展开、纵向结构图和连线线型。Ctrl+滚轮缩放，Ctrl+0 恢复 100%，Alt+F3 适应宽度，Alt+Shift+F3 适应窗口。PageUp / Down 纵向翻页，Ctrl+PageUp / Down 横向翻页。F11 切换全屏。

F3 居中所选主题。F4 同时打开全图概览和分支编辑区，再按 F4 或 Esc 返回。单击概览中的主题可切换分支，也可用滚轮缩放、拖动平移。拖动分隔线可调整两区大小，窄窗口自动改为上下排列。Ctrl+F 查找，Ctrl+Shift+F3 查找下一个。

「视图 → 分支展开层级」可折叠整个分支，或展开一层、两层及全部层级。多选时一次应用到各选中分支。Alt+Shift+0、Alt+Shift+1、Alt+Shift+2 分别对应折叠、展开一层和展开两层。

Alt+1 至 Alt+9 控制当前导图显示层级，Alt+0 展开全部；在分支聚焦时只影响该分支。Alt+D 逐层展开所选分支，Ctrl+F3 折叠或展开所选主题。

大纲与文字格式

F10 或 Ctrl+Shift+O 打开大纲侧栏，导图和大纲共用同一份主题数据。大纲中双击或 F2 改文字，Enter 加同级，Insert 加子级，Tab 缩进，Shift+Tab 提升一级，Shift+Delete 移除条目并保留子级。

选中一个或多个主题，Ctrl+B 切换粗体，Ctrl+I 切换斜体，Ctrl+U 切换下划线，Ctrl+Shift+X 切换删除线，Ctrl+Shift+. / , 调整字号，Ctrl+Shift+D 选文字颜色。F6 打开批量样式。这些格式应用于整个主题；局部富文本暂未实现。

关系线、外框和浮动主题

选起点后按 Ctrl+R，再点终点；Ctrl+Shift+R 插入直线。双击或 F2 改说明，拖黄色控制点调曲率。选中分支后 Ctrl+Shift+B 添加外框，框会随内容伸缩。单击关系线或外框边缘选中，Delete 只删除该对象；Ctrl+C/X/V 复制、剪切和粘贴，单独粘贴需要原主题仍在本文件中。

Alt+F 后点击空白处或空白处双击创建浮动主题；可加子主题，拖到空白处自由摆放，Alt+方向键微移。将分支拖到空白处可以独立出来，拖到另一个主题接回导图；Ctrl 拖动复制，Esc 取消。聚焦时请先返回全图再自由摆放。

新元素需要 SMAP v2，旧版枝理不能打开。SMAP、SVG、PNG、PDF 和 draw.io 支持写出；其他格式尚不能完整保留时会提示并拒绝有损写出。

导入、转换与导出

点击工具栏「格式转换」，选择已有文件、目标格式和另存位置。主题右键菜单可复制当前分支为透明图片，或单独导出该分支。可用「文件」菜单导出全图。

快捷键速查

「帮助 → 快捷键设置」或 Ctrl+Alt+, 打开可搜索的设置页。选中功能，录入按键后选择「替换」或「添加备用键」，最后保存。可以清除、恢复单项或全部默认设置。重复按键会提示冲突，不会抢占其他命令。菜单、按钮提示和状态栏跟随修改更新。

设置页另有「MindMaster 完整对照」，按官方 Windows 快捷键目录列出功能和实现状态。待实现项目没有绑定空命令。编辑框的换行、取消以及大纲中的 Enter / Tab 属于上下文操作，不随画布命令重绑。

窗口底部会随录入、拖动、框选、多选和分支聚焦显示当前可用的操作。将鼠标停在提示或工具栏按钮上可查看详细说明。macOS 的菜单会显示本机对应的按键符号。

  • Ctrl+Alt+B 切换框选模式，Ctrl+A 选择所有可见主题。
  • Ctrl+Shift+F 批量调整样式，Ctrl+Shift+C 复制主题样式，Ctrl+Shift+V 粘贴主题样式。
  • Ctrl+Alt+O 导入导图，Ctrl+Shift+M 打开格式转换。
  • Ctrl+Shift+E 导出当前分支，Ctrl+Alt+I 复制当前分支为透明图片。
  • Ctrl+, 打开外观设置，Ctrl+Alt+1 至 Ctrl+Alt+4 切换导图布局。

启动界面

每次启动默认最大化。枝条生长动画约 1.65 秒，点击或按 Esc、Enter、Space 可立即跳过。「帮助 → 播放启动动画」可关闭以后启动时的动画。
